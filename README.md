# CardNova — סביבת DEV (תבנית אתר חברת אשראי)

תבנית פיתוח **עצמאית ועובדת** לאתר בסגנון חברת אשראי — RTL, עברית, responsive.
המיתוג, הצבעים והתוכן הם **placeholder ניטרלי** ("CardNova") שנועדו להחלפה
בנכסים ובתוכן האמיתיים שלך (design system, לוגו, טקסטים מה-CMS).

> ⚠️ זהו אתר לדוגמה בלבד. הוא אינו מייצג ואינו מתחזה לשום גוף פיננסי אמיתי.
> טופס ההתחברות הוא דמו ואינו שולח או אוסף מידע כלשהו.

## הרצה

אין תלויות ואין build. כל שרת סטטי מספיק:

```bash
# Python
python3 -m http.server 8000

# או Node
npx serve .
```

ואז לפתוח את http://localhost:8000

## מבנה

```
.
├── index.html              # מבנה הדף וכל הסקשנים
├── assets/
│   ├── css/styles.css      # עיצוב, RTL, responsive, משתני CSS (:root)
│   └── js/main.js          # ניווט מובייל, מחשבון הלוואה, טופס דמו
└── README.md
```

## התאמה אישית

- **מיתוג / צבעים** — ערוך את משתני ה-`:root` ב-`assets/css/styles.css`
  (`--brand`, `--accent`, וכו').
- **שם ולוגו** — החלף את `◈ CardNova` ב-`index.html` בנכסים שלך.
- **תוכן** — כל הטקסטים הם placeholder; חבר ל-CMS/API האמיתי.
- **סקשנים** — כרטיסים, הטבות, הלוואות, אזור אישי ושירות — כל אחד עצמאי.

## הערות

- אין קריאות רשת ואין איסוף מידע — הכל רץ בצד הלקוח.
- מחשבון ההלוואה מבצע חישוב אילוסטרטיבי מקומי בלבד (ריבית לדוגמה).
