# SILAVU backend (Supabase)

`migrations/` is the database, applied in order; `functions/` the server code;
`config.toml` the project settings; `templates/` the Auth emails.
Supabase's GitHub integration applies this folder to the production project
(working directory `lumera/backend`) when the branch changes. Setup and
everything else: ADMIN_SETUP.md at the repository root.
